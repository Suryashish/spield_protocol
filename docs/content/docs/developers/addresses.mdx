## Notes

- **Decimals.** USDC, PT, and YT all use **7 decimals** (base units). See [Tokens & units](/docs/developers/tokens).
- **PT/YT are SACs.** The Principal and Yield tokens are Stellar assets wrapped as Stellar Asset Contracts; only the wrapper (tokenization engine) can mint or burn them.
- **Yield source.** The strategy adapter supplies USDC to Stellar's Blend lending market; on mainnet it uses Blend's deep, blue-chip USDC pool.
- **Verify what's running.** Each contract exposes `code_hash()` and `version()` on-chain, so you can confirm exactly which build is live — see [reading state](/docs/developers/reading-state).

<Callout type="warn" title="Addresses can change before mainnet launch">
  While Spield is in development, contracts may be redeployed (especially on testnet) as the
  protocol is refined. Always confirm against the current deployment in the app, and prefer
  reading token addresses from the engine over hard-coding them.
</Callout>
