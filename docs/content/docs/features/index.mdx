## Which product is right for me?

| If you want to… | Use… |
| --- | --- |
| Lock a guaranteed return, simplest possible | **Fixed-Rate Vault** |
| Hold the bond directly, or trade it | **PT** (via Deposit / the market) |
| Take a leveraged view on yield | **YT** (via the market's Long Yield flow) |
| Earn fees from trading activity | **Liquidity** |
| Move USDC over from another chain | **Cross-chain bridge** |
| Verify the protocol is safe | **Solvency dashboard** |

Each feature page explains what it does and how to use it — without exposing how it's built
internally. For the mechanics, see [How It Works](/docs/how-it-works).
